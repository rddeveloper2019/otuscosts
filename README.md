### Техническое задание

+ Аутентификация пользователей (регистрация, вход) + авторизация (экран профиля только для авторизованных пользователей).
+ Главный экран - список товаров либо список операций
+ Добавление/редакториование операций отдельный экран либо модальное окно
+ Добавление категорий (модальное окно)
+ При загрузке данных лоадеры
+ При перезагрузке страницы авторизация пользователя сохраняется
+ Фильтрация операций
+ Экран "Избранное"
+ Смена цветовой схемы
+ Смена языка
+ Обработка ошибок серверных запросов
+ Обработка критических ошибок (error-boundary)
+ Валидация форм добавления/редактирования
+ Деплой
